Hợp đồng API

Tất cả URL dưới đây có prefix /api. Mọi mutation cần cookie phiên và header X-CSRF-Token. /auth/session trả token; đăng nhập thành công thay token và session ID.

Method / pathQuyền / hành vi
GET /health, /configPublic: trạng thái DB, variant cố định, catalog payload demo
GET /auth/sessionPublic: user hoặc null, CSRF token, diagnostic đã che thông tin
POST /auth/login{username,password}; tạo session thật nếu xác thực thành công
POST /auth/logoutHủy session server và cookie
GET /auth/mePhải đăng nhập; thông tin user không chứa hash/password
GET /dashboardUser: dữ liệu mình; admin: toàn hệ thống
GET /tickets?search=&status=&page=Danh sách scope theo role/owner, 8 item/trang
GET /tickets/:idOwner hoặc admin
POST /tickets{title,description,category,priority}; ownerId lấy từ session
PATCH /tickets/:idAdmin; {status,priority}
GET /admin/users, /admin/auditAdmin
POST /admin/usersAdmin; {username,password,name,email,department,role}
PATCH /admin/users/:idAdmin; {active:boolean}; không tự khóa
PATCH /profile{name,email,department}; không nhận role/id

Login diagnostic

inputType là kiểu JSON của password. authQueryExecuted=false nghĩa là validation chặn trước credential lookup; session store và audit vẫn có thể truy cập DB. queryTemplate là mô tả từ source, không phải profiler trace. Chỉ preset đã nhận diện mới hiện payload; thông tin đăng nhập thường được che.

Status codes

400: input/JSON/query syntax sai. 401: không đăng nhập hoặc sai credentials. 403: CSRF/role/owner bị từ chối. 404: không tìm thấy. 409: username trùng. 413: body quá 16KB. 429: vượt 100 lần login/phút/IP. 503: DB không khả dụng.

Chỉ dùng dữ liệu giả lập tại localhost. Tài liệu v1 lưu ở legacy/.
