Yêu cầu và phạm vi

CampusDesk là cổng hỗ trợ sinh viên có hai role admin/user. Bài final so sánh bốn website độc lập: SQL safe/unsafe và MongoDB safe/unsafe trong một repo.

Role

User tạo/xem yêu cầu của mình, xem dashboard cá nhân và cập nhật hồ sơ. Admin xem thống kê toàn hệ thống, quản lý yêu cầu, tạo/khóa tài khoản và xem audit. Quyền được kiểm tra ở backend.

Dữ liệu thật, dữ liệu giả lập

Query chạy trên MySQL/MongoDB thật trong Docker. Người dùng, mật khẩu và yêu cầu đều là dữ liệu giả lập. Dashboard không dùng số liệu hard-code.

Chỉ dùng dữ liệu giả lập tại localhost. Tài liệu v1 lưu ở legacy/.
