Kịch bản demo

Code và luồng bảo mật

Entrypoint hiện tại là src/campus/server.js. Bốn container dùng chung code; VARIANT cố định database và chế độ safe/unsafe. src/app.js và docs/legacy là phiên bản cũ.

Luồng request

Browser → Express JSON parser → session/CSRF → loginInput → repository → quyết định xác thực → session mới. Role và ownership được kiểm tra ở các API bảo vệ.

Điểm lỗi ở MongoDB unsafe

// src/campus/repository.js
async unsafeLogin(username, password) {
  return strip(await users.findOne({ username, password }));
}

password object từ client trở thành predicate. Username vẫn phải là chuỗi. Validator của mongo-unsafe chỉ cho sáu toán tử có giới hạn để giữ phạm vi bài lab; những toán tử đó vẫn bypass query thật.

Đường safe

// src/campus/app.js, sau loginInput
const candidate = await repo.userByUsername(input.username);
user = candidate && verifyPassword(input.password, candidate.passwordHash)
  ? candidate : null;

src/campus/domain.js chặn object trước lookup ở bản safe. Query chỉ tìm username; src/modules/auth/password.js dùng scrypt để verify password riêng. Không có kết quả phù hợp hoặc tài khoản bị khóa thì không tạo session thành công.

Trạng thái hiển thị

Diagnostic trả kiểu password và authQueryExecuted. false nghĩa là validation chặn trước lookup credential, không có nghĩa là toàn bộ request không truy cập session store/audit database. Query hiển thị là diễn giải từ source, không phải log profiler. Chỉ các preset demo đã nhận diện được hiện nguyên payload; thông tin đăng nhập thường được che.

Chứng minh bằng test

tests/campus/auth.test.js dùng repository đếm số lần credential lookup để chứng minh input sai không chạm lookup ở safe; sau đó kiểm tra chuỗi JSON sai không thành operator và mật khẩu đúng vẫn hoạt động. scripts/test-campus-api.js kiểm tra lại cùng các lớp hành vi với MySQL và MongoDB thật qua HTTP, bao gồm quyền admin sau bypass.

SQL comparison

unsafeLogin phía MySQL ghép chuỗi có chủ ý; userByUsername dùng placeholder và bind parameters. ORDER BY trong query unsafe chỉ nhằm ổn định người dùng admin cho demo, không phải yêu cầu của SQL injection.
