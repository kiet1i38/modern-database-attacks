Cấu trúc

Luồng xác thực

GET /auth/session → session + CSRF
POST /auth/login + X-CSRF-Token → validation → DB authentication
→ rotate session ID → save userId + new CSRF → dashboard
GET /auth/me / protected API → reload user from DB → check active + role

Cách ly

Mỗi variant có database, tên cookie và session secret riêng. Database không publish cổng ra host. Cookie là HttpOnly, SameSite=Strict; CSRF kiểm tra token và Origin kể cả giữa các cổng localhost.

Ranh giới unsafe

Chỉ phương thức unsafeLogin ghép input vào SQL hoặc password predicate Mongo. API nghiệp vụ SQL dùng placeholders, Mongo dùng trường do server dựng. Dashboard và phân quyền được chia sẻ nhưng kiểm tra quyền mỗi request.

Phiên bản trước

src/modules và test legacy được giữ để đối chiếu v1; entrypoint mặc định hiện tại là src/campus/server.js. Tài liệu v1 không phải hướng dẫn chạy bản hiện tại.

Chỉ dùng dữ liệu giả lập tại localhost. Tài liệu v1 lưu ở legacy/.
