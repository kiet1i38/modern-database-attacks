API reference

Routes below are prefixed with /api. Mutations require the session cookie and X-CSRF-Token. The session endpoint returns the current CSRF token.

Method and pathAccess and behavior
GET /health, GET /configPublic health and fixed variant configuration.
GET /auth/sessionPublic session state, CSRF token, and redacted diagnostic.
POST /auth/loginAuthenticates credentials and creates a session.
POST /auth/logoutDestroys the server session.
GET /auth/meAuthenticated user without password or hash.
GET /dashboardUser-scoped metrics or admin-wide metrics.
GET /tickets, GET /tickets/:idSearch, filter, paginate, and read tickets within role/owner scope.
POST /ticketsCreates a ticket; owner comes from the session.
PATCH /tickets/:idAdmin changes ticket status or priority.
/admin/users, /admin/auditAdmin-only account and audit operations.
PATCH /profileUpdates the current user's profile; role and ID are not accepted.

Response stability

Localized errors include messageKey and messageParams. The HTTP status, error code, diagnostic structure, and security behavior remain stable across languages. Content-Language and Vary: Accept-Language identify localized responses.

diagnostic.queryTemplate describes source behavior; it is not a database profiler trace. authQueryExecuted=false means validation stopped the credential lookup, not that no session or audit storage was accessed.
