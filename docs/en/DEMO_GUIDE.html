Final presentation guide

Prepare

  1. Start all four Docker services and confirm they are healthy.
  2. Open the four local URLs and point out the separate database and safe/unsafe mode.
  3. Use only the synthetic admin and student accounts documented in the run guide.

Suggested walkthrough

  1. Show the same login and dashboard in SQL and MongoDB variants.
  2. Compare the unsafe login demonstration with the corresponding safe implementation.
  3. Show a user creating and viewing their own tickets, then show an admin managing tickets and accounts.
  4. Demonstrate the language switcher on login and inside the app. Confirm a selected language follows variant links.
  5. Open diagnostics and explain that ordinary credentials are redacted and query templates are explanatory source descriptions.
  6. Show the integration report and point out which checks run against real local databases.

Simulation panel

Scenario cards model risks such as excessive data exposure, unauthorized changes, destructive operations, privilege changes, error disclosure, and session/ownership failures. Simulation results are illustrative; distinguish them from live API checks.

Never enter a real password or real personal information during the presentation.
