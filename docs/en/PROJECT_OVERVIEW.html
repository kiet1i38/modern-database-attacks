Project overview

Final project scope

CampusDesk is a student support portal with admin and user roles. The final demo compares four independent applications in one repository.

VariantDatabaseLogin behaviorLocal URL
SQL UnsafeMySQLIntentionally concatenates login inputhttp://localhost:3001
SQL SafeMySQLParameterized lookup and scrypt password verificationhttp://localhost:3002
MongoDB UnsafeMongoDBBounded Mongo operator predicate demonstrationhttp://localhost:3003
MongoDB SafeMongoDBStrict string validation and scrypt password verificationhttp://localhost:3004

Roles

  • User: personal dashboard, own support tickets, and profile updates.
  • Admin: system-wide dashboard, ticket management, account management, and audit history.

Authorization and ticket ownership are enforced by the backend on every protected request. All seeded people, passwords, and tickets are synthetic. Dashboards query the selected database.
