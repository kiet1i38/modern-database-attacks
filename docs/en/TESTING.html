Testing and evidence

Automated coverage

  1. Unit/auth tests: validation, password storage, redaction, role checks, sessions, and injection cases.
  2. Hosted configuration tests: opt-in settings, TLS requirements, and Vercel routes.
  3. i18n checks: matching locale keys, interpolation placeholders, required labels, and API/frontend message-key parity.
  4. HTTP integration: all four Docker apps, real MySQL/MongoDB, login payloads, CSRF, roles, ownership, ticket operations, account lock, and cross-variant cookie isolation.
  5. Build: TypeScript checks and production Vite bundle.

Commands

npm test
npm run test:legacy
npm run test:i18n
npm run build
docker compose up -d --build --wait --wait-timeout 240
npm run test:integration

Integration results are written as api-results.json and api-results.log in a timestamped evidence/ folder. The suite creates synthetic QA records and changes a demo ticket/account while running.

Manual browser check

For each variant, verify Vietnamese default, English query/cookie selection, login/logout, role-specific dashboard, ticket filters and pagination, forms, dialogs, and locale changes while a form is open. Check that the language carries across variant links and that errors are readable in both languages.
