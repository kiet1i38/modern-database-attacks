Development guide

Run the frontend locally

docker compose up -d --build --wait
npm ci
npm run dev

Vite serves the frontend at http://localhost:5173 and proxies API requests to MongoDB Safe on port 3004. This is a development endpoint, not a fifth demo variant.

Useful checks

npm run test:i18n
npm test
npm run test:legacy
npm run build
npm run test:integration

Code map

  • UI and language-aware views: frontend/src/main.tsx, frontend/src/demo-panel.tsx.
  • Locale dictionaries and selection: frontend/src/i18n/.
  • API locale parsing and translations: src/campus/i18n/.
  • Routes and domain rules: src/campus/app.js and src/campus/domain.js.
  • Integration evidence: scripts/test-campus-api.js.

Keep safe and unsafe behavior explicit in tests. Do not claim a payload bypasses authentication unless the selected real database variant has been exercised.
