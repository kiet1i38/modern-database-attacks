Phát triển và cấu trúc code

Frontend development

docker compose up -d --build --wait
npm ci
npm run dev

Vite trên localhost:5173, proxy API tới Mongo Safe localhost:3004. Frontend dev chỉ là môi trường phát triển, không phải website thứ năm trong bài demo. Đổi proxy trong frontend/vite.config.ts nếu cần kiểm tra variant khác.

Build/check

npm run build
npm test
npm run test:legacy
docker compose config --quiet
docker compose up -d --build --wait

Sau khi sửa backend hoặc docs, build lại image. Không dùng test legacy làm bằng chứng cho chức năng CampusDesk mới. Khác biệt local tồn tại trước triển khai được giữ riêng, không tự động đưa vào commit mới.

Thêm payload

Catalog ở src/campus/domain.js; thêm assertion vào scripts/test-campus-api.js và browser evidence. Không ghi payload là bypass nếu chưa chạy với query/database thực tế.

Chỉ dùng dữ liệu giả lập tại localhost. Tài liệu v1 lưu ở legacy/.
