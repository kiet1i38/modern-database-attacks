Bốn bản demo trên Vercel

Mỗi bản dùng một project Vercel và database riêng. Nhánh triển khai của đợt này là demo_updated. Các alias ổn định để mở từng bản:

  • SQL Unsafe
  • SQL Safe
  • MongoDB Unsafe
  • MongoDB Safe

Thêm ?lang=en để mở bằng tiếng Anh. Bộ chọn ngôn ngữ cập nhật URL và ghi nhớ lựa chọn trên từng host.

Cấu hình project

Bốn project dùng Framework Preset Other, thư mục gốc repository, Node.js theo cấu hình project, build npm run build:vercel và output dist. Mỗi project đặt VARIANT cố định tương ứng: sql-unsafe, sql-safe, mongo-unsafe hoặc mongo-safe. API được Vercel route qua api/index.js.

Project production dùng các biến môi trường Production đã cấu hình trong Vercel. Không đưa connection string, session secret, cookie, mật khẩu hoặc token vào Git, ảnh chụp hay log. Việc triển khai ứng dụng không chạy lệnh reset hoặc seed lại database.

Kiểm tra sau triển khai

  1. Mở /api/health và /api/config trên từng alias; xác nhận API sẵn sàng và đúng loại database/variant.
  2. Mở trang với ?lang=vi và ?lang=en; đăng nhập tài khoản synthetic, đổi ngôn ngữ và kiểm tra dashboard theo role.
  3. Kiểm tra link chuyển variant, logout và session riêng giữa các project.
  4. Chỉ dùng dữ liệu giả lập. Hai bản Unsafe cố ý có lỗ hổng đăng nhập để trình diễn; không dùng tài khoản thật hoặc dữ liệu nhạy cảm.

Build thành công không tự chứng minh API có thể kết nối database. Nếu health trả lỗi, xem cấu hình biến Production và trạng thái provider; ứng dụng không trả thông tin kết nối ra trình duyệt.
