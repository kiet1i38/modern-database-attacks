Kiểm thử và bằng chứng

Các lớp test

  1. Unit: validation, seed/password storage, redaction, enum và ownership input.
  2. Integration: HTTP thật trên bốn app với MySQL/MongoDB Docker; payload, session, CSRF, role, ownership, account lock, CRUD.
  3. Browser: form login, mọi payload preset, dashboard, modal, hồ sơ, user management, mobile, console/network và XSS dạng literal.
  4. Resilience: restart app, DB outage/recovery, expiry và reset đúng database.

Chạy lại

npm test
npm run test:integration
npx --yes --package @playwright/cli playwright-cli -s=campus open http://localhost:3001
npx --yes --package @playwright/cli playwright-cli -s=campus snapshot

Script browser tại scripts/browser-campus.js là hàm dùng với Playwright CLI run-code. Hướng dẫn chính xác nằm trong scripts/run-browser-evidence.ps1. Browser capture gốc ở output/playwright; bản đối chiếu nằm trong evidence.

Bằng chứng lần triển khai này

Mở báo cáo HTML · API results JSON. Báo cáo chỉ ghi các kiểm tra thực sự chạy, tách HTTP 400/401/403 mong đợi khỏi lỗi UI.

Screenshot chứng minh trạng thái hiển thị, không tự chứng minh mọi kiểm tra backend. Kết hợp ảnh với test assertion và log. Không lưu cookie/token/mật khẩu thông thường trong log mới.

Giới hạn

Không phải pentest mọi lỗ hổng, kiểm thử tải lớn hoặc xác minh trên mọi trình duyệt/OS. Dependency audit là snapshot tại thời điểm chạy.
