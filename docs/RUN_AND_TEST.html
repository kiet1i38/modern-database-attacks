Cách chạy, truy cập và xử lý lỗi

1. Chuẩn bị

Cài Docker Desktop và mở Docker trước. Nếu chạy test trên host, cần Node.js ≥22.12 và npm. Không cần MongoDB/MySQL cài sẵn, không cần tạo file .env cho Docker.

git clone https://github.com/kiet1i38/modern-database-attacks.git
cd modern-database-attacks
docker compose up -d --build --wait --wait-timeout 240

2. Truy cập

Mở localhost:3001, :3002, :3003, :3004. Admin: admin / Admin@123. User: student / Student@123, user thứ hai: student2 / Student2@123. Tài khoản được seed tự động khi database rỗng.

3. Chạy test

npm ci
npm test
npm run test:integration
npm run build
npm audit --omit=dev

Test integration ghi kết quả vào một thư mục evidence theo thời gian chạy. Test tạo dữ liệu QA giả lập; hãy reset trước khi trình bày.

4. Reset dữ liệu demo

Những lệnh sau xóa session, audit, yêu cầu và tài khoản của đúng bốn database CampusDesk, rồi seed lại. Không chạy khi bạn muốn giữ dữ liệu demo đang chỉnh.

docker compose exec -T sql-unsafe npm run db:reset
docker compose exec -T sql-safe npm run db:reset
docker compose exec -T mongo-unsafe npm run db:reset
docker compose exec -T mongo-safe npm run db:reset

5. Xem lỗi và dừng

docker compose ps
docker compose logs --tail=80 sql-safe
docker compose logs --tail=80 mysql mongodb
docker compose down
Hiện tượngCách xử lý
Cannot connect to Docker daemonMở Docker Desktop, đợi engine ready rồi chạy lại.
Cổng 3001–3004 bị chiếmKiểm tra tiến trình sở hữu cổng, không tự tắt dịch vụ khác. Sửa cổng host trong Compose nếu cần và cập nhật các link/test.
Database unavailable / HTTP 503Xem health và log database; đợi database ready, chạy lại docker compose up -d --wait.
HTTP 403 CSRFReload trang. API client phải gọi /auth/session và gửi token mới sau login.
HTTP 400/401 khi gửi payload vào safeĐây là kết quả mong đợi nếu payload không được chấp nhận hoặc không khớp tài khoản.
MySQL access denied sau đổi mật khẩu ComposeVolume giữ cấu hình cũ; trả cấu hình demo ban đầu. Chỉ xóa volume nếu chủ động chấp nhận mất toàn bộ dữ liệu lab.

Không publish ứng dụng unsafe lên Internet. Dừng bằng docker compose down sẽ giữ volume; không thêm -v nếu muốn giữ dữ liệu.

Chỉ dùng dữ liệu giả lập tại localhost. Tài liệu v1 lưu ở legacy/.
