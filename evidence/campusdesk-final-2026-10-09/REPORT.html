Những vấn đề đã xử lý

  • Docker simultaneous image tag collision: unique Compose service image names
  • SQL login tautology row ordering: server-owned ORDER BY on a new line; extra-account regression tested
  • Chromium HTML pattern v flag: escaped username hyphen
  • Search focus: input remains mounted across query refresh
  • Mobile browser harness: transformed sidebar checked by state, not visibility alone
  • Re-running browser harness: unique ticket title per test avoids ambiguous locators

Lịch sử các lần chạy được giữ nguyên để đối chiếu: attempt-01 · attempt-02 · attempt-03 · attempt-04. Attempt 01: thao tác menu và pattern HTML; 02: tên yêu cầu trùng khi chạy lại; 03: assertions đạt nhưng ảnh chụp giữa transition; 04: ảnh đã ổn định làm lộ thao tác bấm giữa overlay bị drawer che. Lần final bấm vùng nền bên phải như người dùng. Số liệu phía trên chỉ thuộc lần final, không cộng dồn lần thất bại. Screenshot tắt animation chỉ lúc chụp để ảnh rõ; thao tác UI vẫn dùng animation mặc định.

Giới hạn

  • Chromium only; not Firefox/Safari
  • Session expiry exercised at 200ms with real DB store; application default 30 minutes not waited in real time
  • No high-load testing, Internet deployment or complete security certification
  • Unexpected HTTP 400/401/403 are distinguished from intentionally negative authentication tests
  • Legacy evidence and unrelated pre-existing working changes are not evidence for this implementation
